Code I am learning

This is a small C++ example of operator overloading. A friend function lets me print my own class with cout, just like a normal number. We study this in our OOP class.

class Distance {
    int feet, inches;
public:
    Distance(int f, int i) : feet(f), inches(i) {}

    friend ostream& operator<<(ostream& out, const Distance& d) {
        out << d.feet << " ft " << d.inches << " in";
        return out;
    }
};

// cout << Distance(5, 7);   prints: 5 ft 7 in
