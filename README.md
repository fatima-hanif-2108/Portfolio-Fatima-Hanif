# Fatima Hanif | Personal Portfolio Website

Hello! I am **Fatima Hanif**, a BS Computer Science student at **International Islamic University, Islamabad (IIUI)**. This is my personal portfolio website. It shows my projects, skills, education and certificate.

🔗 **Live website:** [fatima-hanif-2108.github.io/Portfolio](https://fatima-hanif-2108.github.io/Portfolio/)

## ✨ Features

- Responsive design (works on phone, tablet and computer)
- Light and dark mode button
- Smooth scroll animations and a typing effect
- Scroll progress bar at the top
- Interactive 4-bit binary counter demo
- Sections for About, Journey, Skills, Projects, Code and Certificate

## 🛠️ Built With

- **HTML5**
- **CSS3** (Grid, Flexbox, animations, CSS variables)
- **JavaScript** (typing effect, scroll reveal, counter, theme toggle)
